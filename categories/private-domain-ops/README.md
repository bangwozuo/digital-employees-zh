# 私域运营 (Private Domain Operations)

> 为私域运营团队提供社群管理、用户分层、SOP执行、转化漏斗优化等数字员工能力。

## 目标用户

- 私域运营
- 社群经理
- 用户增长
- 电商运营

## 典型痛点

- 社群SOP执行依赖人工，易遗漏
- 用户分层标签更新不及时
- 转化漏斗断点难以定位
- 复购提醒时机把握不准

## 推荐数字员工资产包

- `de_private_domain_ops_assistant` — 私域运营助手

## 推荐业务技能

- `community_sop_execution`
- `user_segmentation`
- `conversion_funnel_analysis`
- `repurchase_reminder`

## 推荐业务连接器

- `wechat_work_api`
- `enterprise_wechat`
- `scrm_platform`
- `shopify_api`

## 推荐场景工作流

- `new_user_onboarding_sop`
- `vip_retention_flow`
- `flash_sale_alert_flow`

## 高频日常任务

- `execute_daily_sop_tasks`
- `update_user_tags`
- `monitor_community_health`

## 高频定时任务

- `weekly_lifecycle_stage_report`
- `monthly_ltv_analysis`

## 平台导入说明

```bash
# 1. 克隆仓库
git clone https://github.com/your-org/digital-employees-zh.git

# 2. 进入资产包目录
cd digital-employees-zh/categories/private-domain-ops/employees/de_private_domain_ops_assistant

# 3. 使用 DevKit 校验
devkit validate .

# 4. 导出为平台导入格式
devkit export . --output ./dist

# 5. 在数字员工平台上传 dist/ 目录下的 ZIP 和 manifest.json
```
