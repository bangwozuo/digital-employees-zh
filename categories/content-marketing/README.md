# 内容营销 (Content Marketing)

> 为内容团队提供选题策划、多平台分发、SEO优化、数据复盘等数字员工能力。

## 目标用户

- 内容运营
- 新媒体编辑
- SEO专员
- 品牌负责人

## 典型痛点

- 选题灵感枯竭，热点跟进慢
- 多平台分发格式适配繁琐
- SEO关键词布局缺乏数据支撑
- 内容效果复盘维度单一

## 推荐数字员工资产包

- `de_content_marketing_assistant` — 内容营销助手

## 推荐业务技能

- `topic_mining`
- `multi_platform_adaptation`
- `seo_optimization`
- `content_performance_analysis`

## 推荐业务连接器

- `wechat_official`
- `xiaohongshu_api`
- `zhihu_api`
- `google_search_console`

## 推荐场景工作流

- `content_calendar_pipeline`
- `viral_topic_alert_flow`
- `seo_audit_flow`

## 高频日常任务

- `scan_trending_topics`
- `draft_daily_posts`
- `reply_to_comments`

## 高频定时任务

- `weekly_content_performance_report`
- `monthly_competitor_content_audit`

## 平台导入说明

```bash
# 1. 克隆仓库
git clone https://github.com/bangwozuo/digital-employees-zh.git

# 2. 进入资产包目录
cd digital-employees-zh/categories/content-marketing/employees/de_content_marketing_assistant

# 3. 使用 DevKit 校验
devkit validate .

# 4. 导出为平台导入格式
devkit export . --output ./dist

# 5. 在数字员工平台上传 dist/ 目录下的 ZIP 和 manifest.json
```
