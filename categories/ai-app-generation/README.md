# AI应用生成 (AI App Generation)

> 为AI应用开发者提供Prompt工程、模型选型、应用原型生成、效果评估等数字员工能力。

## 目标用户

- AI应用开发者
- Prompt工程师
- 低代码开发者
- 创新实验室

## 典型痛点

- Prompt设计效率低，效果不稳定
- 模型选型缺乏系统性对比
- 应用原型开发周期长
- 效果评估指标不统一

## 推荐数字员工资产包

- `de_ai_app_generator` — AI应用生成器

## 推荐业务技能

- `prompt_optimization`
- `model_selection_advisor`
- `prototype_scaffolding`
- `eval_pipeline_design`

## 推荐业务连接器

- `openai_api`
- `anthropic_api`
- `huggingface_api`
- `langsmith_api`

## 推荐场景工作流

- `prompt_iterative_refinement`
- `model_ab_test_flow`
- `app_deploy_checklist`

## 高频日常任务

- `run_prompt_regression_tests`
- `collect_user_feedback_samples`
- `update_model_benchmark`

## 高频定时任务

- `weekly_model_performance_report`
- `monthly_cost_analysis`

## 平台导入说明

```bash
# 1. 克隆仓库
git clone https://github.com/your-org/digital-employees-zh.git

# 2. 进入资产包目录
cd digital-employees-zh/categories/ai-app-generation/employees/de_ai_app_generator

# 3. 使用 DevKit 校验
devkit validate .

# 4. 导出为平台导入格式
devkit export . --output ./dist

# 5. 在数字员工平台上传 dist/ 目录下的 ZIP 和 manifest.json
```
