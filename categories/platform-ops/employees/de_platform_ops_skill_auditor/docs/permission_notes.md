# 权限说明 — 平台运营技能审核助手

## 所需 API 权限

### Platform Api

- **读取权限**：需要访问基础数据接口
- **写入权限**：如需回写数据，需额外申请写入 scope
- **频率限制**：默认 100 次/分钟，大流量场景请联系平台提升限额

### Moderation Api

- **读取权限**：需要查询接口权限
- **通知权限**：如需发送消息，需申请消息推送 scope

## 数据隐私

- 本资产包不会存储敏感个人信息
- 所有 API 调用均通过平台加密通道传输
- 建议定期轮换 API Key

## 合规提示

- 使用本资产包需遵守各连接器平台的服务条款
- 涉及用户数据的场景请确保已获得用户授权
- 财务、法务相关输出仅供参考，不构成专业建议

## 最小权限原则

建议为数字员工创建独立的 API Key，仅授予完成任务所需的最小权限集合，避免使用超级管理员凭证。
